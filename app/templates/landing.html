1

Detect the watermark type

Refine identifies whether the content carries pixel-level frequency watermarks (SynthID) or token-probability signatures embedded in AI text output.

2

Apply targeted perturbations

For images: 2D FFT phase noise injected at frequencies above the threshold distance from the DC component. For text: homoglyph replacement and ZWS insertion disrupt n-gram classifiers.

3

Reconstruct with quality intact

The inverse FFT reconstructs the image. Text remains human-readable. The scrambled content is indistinguishable to a human reader but statistically de-coupled from the original watermark.

FFT

Fourier Scrambling

Perturbs high-frequency phase maps. Targets pixel-level embedding coordinates used by SynthID.

SYN

Synonym Mapping

Replaces watermark-biased tokens with semantically equivalent alternatives from a local thesaurus.

ZWS

Zero-Width Insert

Injects invisible Unicode characters to fracture n-gram hash chains without changing what you read.

JIT

Spatial Jitter

Micro-rotation and sub-pixel rescaling decouples pixel alignment from grid-based watermark patterns.

Self-Host in 30 Seconds

Three ways to run Refine. No Docker account, no registration, no cloud dependency.

PY

Python (pip)

$ git clone https://github.com/askabouthasheem/refine
$ pip install -r requirements.txt
$ python run.py

Requires Python 3.10+. Runs on http://localhost:8000

🐳

Docker

$ docker run -p 8000:8000 \
  --rm Refine/Refine
# or build from source:
$ docker build -t Refine .
$ docker run -p 8000:8000 Refine

No Python install needed. Image is ~180 MB.

ENV

Virtualenv

$ git clone https://github.com/askabouthasheem/refine && cd refine
$ python -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ python run.py

Isolated environment, no global packages.

For images, tools like SynthID embed signatures by making imperceptible pixel-level changes in the frequency domain. For text, LLMs apply a pseudo-random "green/red" token partition keyed to a secret hash of prior tokens, biasing word selection in a statistically detectable pattern. Metadata stripping removes text tags like EXIF or IPTC stored alongside the image file — these are trivially deleted and provide no real provenance guarantee. Invisible watermarks like SynthID are embedded directly into the pixel structure, so deleting metadata does nothing. Refine targets the pixel-level and frequency-domain structures where the actual watermark payload lives.
